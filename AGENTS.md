# Agent conventions

- Preserve the neutral minimalist visual system and semantic CSS variables.
- Keep claims limited to verified reference data.
- Do not add employment, achievements, metrics, URLs, or credentials without source evidence.
- Use TypeScript strict mode and Astro static rendering.
- Centralize personal and project metadata in `src/data/site.ts`.
- Keep public assets outside private reference documents.
- Do not expose phone numbers, API keys, credentials, webhook identifiers, or private URLs.
- Reuse existing layout, header, footer, project-card, and case-study patterns.
- Add descriptive alt text and explicit image dimensions.
- Verify `npm run build` after content or layout changes.
